# 🍽️ Restaurantly-Restaurant Website

<img width="1350" height="628" alt="image" src="https://github.com/user-attachments/assets/b67cacda-7f44-426b-9da1-b64636934b6d" />

Restaurantly is a modern, responsive restaurant website built with **HTML, CSS, JavaScript, and Bootstrap**.  
It is designed to showcase restaurant services, menus, and contact information with a professional and elegant layout.

---

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript
- **Icons:** Font Awesome
- **Fonts:** Google Fonts
---

##🚀 Features
- Responsive design for mobile, tablet, and desktop.
- Sticky navigation bar with smooth scrolling.
- Sections for **About Us, Menu, Why Us, Gallery, Contact, and Reservation**.
- Integrated Google Maps (if added).
- Clean UI with hover and scroll effects.
- Easy to customize.
---

## 🖼 Sections Overview
- **🏠 Home** – Hero section with restaurant name and tagline.
- **ℹ️ About Us** – Introduction about the restaurant, story, and values.
- **🍴 Menu** – Highlighted dishes with categories and pricing (if added).
- **⭐ Why Us** – Key reasons to choose the restaurant (quality, service, ambiance, etc.).
- **📷 Gallery** – Collection of food and restaurant images.
- **📞 Contact** – Contact details, phone number, email, and location.
- **📝 Reservation** – Booking form for customers to reserve a table.
- **🔝 Navbar** – Sticky navigation bar for smooth scrolling across sections.
